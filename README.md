# NftDraft

NftDraft is a high-performance, multi-tenant platform for real-time data processing and auto-scaling, empowering digital asset builders and generators.

With NftDraft, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/NftDraft.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure NftDraft, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
